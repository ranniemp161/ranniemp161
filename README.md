# Hey, I'm Rannie! 👋

### Software Engineer | Full-Stack Developer | Systems Thinker

I build software, design systems, and occasionally question the meaning of existence.

I'm a software engineer who believes there's a significant difference between **knowing how to write code and understanding how software actually works.**

Writing code is one thing. Understanding how your application communicates with databases, how APIs handle requests, how infrastructure scales, and what happens when something breaks in production? That's where engineering gets interesting.

My focus is on building **maintainable, scalable, and secure applications**, from frontend interfaces to backend services and cloud infrastructure.

I'm also a professional video editor, a philosophy enthusiast, and someone who asks *"But why?"* probably more often than necessary.

---

## 🧠 My Engineering Philosophy

> Don't just make it work. Understand why it works, how it fails, and what it takes to keep it running.

I care about:

- **System Design:** Architecture, scalability, performance, and engineering trade-offs.
- **Backend Engineering:** RESTful APIs, authentication, database design, and business logic.
- **Cloud Infrastructure:** Serverless deployments, VPS environments, reverse proxies, CDNs, and application security.
- **Software Quality:** Maintainable code, separation of concerns, and practical engineering decisions.
- **AI-Assisted Development:** Using AI to accelerate engineering without outsourcing critical thinking.

I'm not interested in adding complexity just to make an architecture diagram look impressive.

**The best architecture is the one that solves the actual problem.**
